# Tushar's Birthday Surprise 🎉

A high-end, responsive Single Page Application (SPA) built with React, Tailwind CSS, and Framer Motion.

## Features

- ✨ **CSS Scroll Snapping** - Perfect viewport locking for each section
- 💖 **Floating Hearts Animation** - Subtle romantic overlay
- 📸 **Polaroid Gallery** - Staggered fade-in animations
- ⌨️ **Typewriter Effect** - Scroll-triggered letter animation
- 🎥 **Video Player** - Autoplay on viewport with bloom effect
- 🖼️ **Lazy Loading** - Optimized image loading for fast FCP

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Customization

### Replace Images
Update the `memories` array in `src/components/Gallery.jsx` with your own images.

### Replace Video
Update the video source in `src/components/VideoSection.jsx` with your video URL.

### Update Letter Text
Edit the `letterText` variable in `src/components/Letter.jsx`.

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
